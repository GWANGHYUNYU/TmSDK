## 4. 결과 3 — ★ 공기 VPD 는 실제 부하를 절반으로 과소평가합니다

```
VPD(leaf-to-air) = es(T_leaf) − RH × es(T_air)     ← 본 과제의 목표량
VPD(air)         = es(T_air) × (1 − RH)            ← 센서가 출력하는 값
es(T) = 0.61078 · exp( 17.27T / (T+237.3) )   [kPa]
```

환경센서 10일치(1분 간격 11,875행)를 슬롯 3분 구간으로 평균해 붙였고,
**390행 전부 결합 성공**했습니다. 센서 CSV 의 `VPD` 열이 **공기 VPD** 임을
검증했습니다(가설식과 평균 절대오차 0.0053 kPa, 일치율 86 %).

| 카메라 | 구분 | 공기 VPD | 잎 VPD A | 잎 VPD B | 잎 VPD C | 개체간 최대차 |
|---|---|---|---|---|---|---|
| `.151` No Fan | 주간 | 0.857 | **1.711** | 1.576 | 1.674 | 0.136 |
| `.151` No Fan | 야간 | 0.414 | 0.673 | 0.694 | 0.650 | 0.043 |
| `.152` With Fan | 주간 | 0.857 | **1.357** | 1.209 | 1.344 | 0.147 |
| `.152` With Fan | 야간 | 0.414 | 0.643 | 0.665 | 0.619 | 0.046 |

단위 kPa · 딸기 목표대 0.6~1.2 kPa

**목표 범위 이탈률**

| 대상 | 주간 이탈 | 야간 이탈 |
|---|---|---|
| 공기 VPD (센서) | **8.1 %** | 89.9 % |
| 잎 VPD (`.151` No Fan) | **94~97 %** | 44~47 % |
| 잎 VPD (`.152` With Fan) | 64~91 % | 48~56 % |

> **단일 공기 센서로 보면 주간에 8 % 만 이탈이지만, 실제 잎 기준으로는
> 무송풍 구역에서 95 % 가 목표 상한을 넘습니다.**
> 이 과제의 존재 이유를 데이터가 직접 보여 줍니다.

### ⚠ 절대 보정 불확실성 — 결론에 미치는 영향

야간(소등) 잎−기온이 **+1.98 ℃ (`.151`), +1.77 ℃ (`.152`)** 입니다.
소등 시 증산이 멈추면 잎은 기온과 평형(복사냉각으로 오히려 −0.5~0 ℃)이
정상이므로 **이 값은 과대합니다.** 원인은 둘 중 하나입니다.

- (a) **열화상 절대 오프셋** — 카메라 사양 ±2 ℃ 와 부합
- (b) **공기센서 위치가 캐노피보다 서늘함** — 센서가 레일 상단에 부착됨

| 시나리오 | `.151` 잎−기온 | `.151` 잎 VPD | 공기 VPD 대비 초과 |
|---|---|---|---|
| 보정 없음 (원측정) | +4.23 ℃ | 1.653 | +0.796 |
| 야간평형 가정 보정 (−1.98 ℃) | +2.24 ℃ | 1.258 | +0.401 |

**보정을 최대로 걸어도 다음 세 결론은 유지됩니다.**

1. 주간 잎 VPD > 공기 VPD (부등호 방향 불변)
2. 팬이 잎−기온을 1.74 ℃ 낮춤 (야간 오프셋이 두 구역 비슷해 비교 유효)
3. **개체 간 차이 0.14 kPa** — 같은 카메라 내부라 오프셋이 완전 상쇄됨

> 접촉식 엽온센서가 도착하면 (a)/(b) 를 판정할 수 있습니다. **미해결.**

## 8. ⚠ 사용 금지 — `.152` 의 POT C

`.152` 의 화분 좌표는 **현장에서 확인한 적이 없습니다.** `.151` 좌표를 그대로
옮겨 썼는데, 두 카메라의 화각이 다릅니다.

| 근거 | `.151` | `.152` |
|---|---|---|
| 지속 냉점 밴드(= 화분열)가 있는 행 | y = 0~24 | **y = 7~40** |
| POT C 의 지속 편차 (프레임평균 대비) | −0.69 ℃ (차가움 = 화분) | **+0.52 ℃ (뜨거움)** |

**`.152` 의 POT C 원은 일사센서(pyranometer)와 32.9 % 겹칩니다.** 일사센서는
주간에 프레임평균보다 +1.9 ℃(최대 +5.8 ℃) 높은 지속 고온체입니다.

> **`marker_timeseries.csv` 의 `pot_C` · `VPD_pot_C` 는 `camera = 152` 행에서
> 사용하지 마십시오.** `camera = 151` 행은 정상입니다.

**잎 마커는 영향 없습니다.** LEAF A/B/C 는 `.152` 에서도 캐노피 위에
떨어집니다(일사센서 겹침 0 %). 마커 하나만 써서 계산해도 팬 효과는
1.62~1.85 ℃ 범위로 유지되므로 **§5 의 1.74 ℃ 는 그대로 유효**합니다.
다만 "개체 A/B/C" 라는 이름이 `.151` 의 A/B/C 와 같은 그루라는 뜻은 **아닙니다.**
