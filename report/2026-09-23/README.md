## 1. 무엇이 새로 가능해졌나

이전([중간보고](../mid-term/README.md))에는 **손으로 찍은 마커 3개**로 두 구역을
비교했습니다. 이번에는 **개체 107개**를 캘리브레이션·어노테이션 기반으로 잡아,
같은 기준으로 두 구역을 봅니다.

| | `.151` 무송풍 | `.152` 송풍 |
|---|---|---|
| 마스크 근거 | RGB 어노테이션 → 층별 H(d) **투영** | 열화상에 **직접** 작도 |
| 이유 | RGB 와 스테레오 캘리브레이션 완료 | RGB 와 매칭 없음 |
| 개체 | 75 (잎 60 · 꽃 12 · 딸기 3) | 32 (잎 29 · 딸기 1 · 엽온센서 2) |
| 쓸 수 있는 날 | 5일 (09-17·18·19·20·22) | 6일 (09-18~09-23) |

`.152` 는 분류를 **잎만** 찍었습니다. 열화상으로는 꽃 66 % · 딸기 44 % 로
갈리지 않기 때문입니다([분할 가이드](../../docs/segmentation_guide.md) §0).
딸기 1개는 RGB 영상으로 따로 확인한 것이고, 그 사실이 데이터에 적혀 있습니다.

## 2. ★ 핵심 결과 — 송풍 효과가 개체 단위로 확인됩니다

**같은 날 두 구역의 잎 평균** (단위 ℃)

| 날짜 | `.151` 점등 | `.152` 점등 | 차이 | `.151` 소등 | `.152` 소등 | 차이 |
|---|---|---|---|---|---|---|
| 09-19 | 25.37 | 24.82 | **+0.55** | 19.89 | 19.85 | +0.04 |
| 09-20 | 25.96 | 25.41 | **+0.55** | 20.03 | 19.95 | +0.07 |
| 09-22 | 25.39 | 24.94 | **+0.45** | 19.95 | 19.94 | +0.01 |

> **점등 중에는 무송풍 구역이 0.45~0.55 ℃ 높고, 소등 중에는 차이가
> 0.01~0.07 ℃ 로 사라집니다.**

이 «밤에 사라진다» 가 핵심입니다. 두 카메라의 절대 오프셋이나 화각 차이에서
오는 편향이라면 밤에도 그대로 남아야 합니다. 사라진다는 것은 이것이
**점등 중 기류가 만든 실제 온도차**라는 뜻입니다.

> ⚠ 09-18 은 표에서 뺐습니다. 그 날 `.151` 은 점등 슬롯이 4개뿐이라
> (나머지가 0 바이트) 하루를 대표하지 못합니다.
>
> ⚠ 이 값은 **잎끼리의 차이**입니다. 중간보고의 «팬 효과 1.74 ℃» 는
> **잎−기온** 차이라서 직접 비교할 수 없습니다. 같은 현상을 다른 양으로
> 본 것입니다.

## 4. 개체 간 편차 — 이 과제가 겨냥한 값

중앙값, 단위 ℃

| | 점등 | 소등 |
|---|---|---|
| `.151` 무송풍 | 0.402 ~ 0.467 | 0.125 ~ 0.257 |
| `.152` 송풍 | 0.538 ~ 0.653 | 0.166 ~ 0.283 |

점등 중 개체 간 편차가 소등 대비 **2~3배**입니다. 두 구역, 11일, 두 가지
전혀 다른 마스크 방식에서 모두 같은 방향으로 나옵니다.

일자별 그래프([`figures/일자별/`](figures/일자별))를 보면 하루 안에서도
편차가 일정하지 않습니다 — **점등 직후(08:00~09:00)에 가장 크고** 낮 동안
완만히 줄다가, 소등 무렵 다시 한 번 튑니다.

## 5. 데이터를 믿어도 되는 근거

### 5-1. 날짜마다 «마스크를 쓸 자격» 을 심사했습니다

어노테이션은 특정 시각 한 장에 찍었습니다. 다른 날에 쓰려면 그 사이 장면이
안 움직였어야 합니다. 날마다 기준 프레임과 상호상관해 판정합니다.

| 판정 | 뜻 | 날 수 |
|---|---|---|
| 확인 / 주의 | 이동 (0,0), 슬롯 간 일관 | 8 |
| 보정 | 1~2 화소 일관 이동 → 되밀어 씀 | 3 |
| 불가 | 슬롯마다 최적 이동이 제각각 = 정렬 근거 없음 | 7 |
| 판정불가 | 주간 슬롯이 없어 심사 자체가 불가 | 2 |

전체 19 카메라-일 중 **11일만** 채택했습니다. 근거는
[`data/leaf_temp_days.csv`](data/leaf_temp_days.csv) 에 전부 남아 있습니다.

### 5-2. 교차검증 — 개체별 편차가 기준일과 같은가

| 카메라 | 날짜별 상관 r |
|---|---|
| `.151` | +0.867 ~ +1.000 |
| `.152` | +0.934 ~ +1.000 |

**채택한 11일 전부 r ≥ 0.867** 입니다. 마스크가 같은 잎을 덮고 있다는 뜻으로,
화면 상호상관보다 강한 증거입니다 — 그 날 열 구조가 얼마나 뚜렷한지에
좌우되지 않기 때문입니다.

### 5-3. 어노테이션 품질을 개체마다 적었습니다

`.152` 는 열화상에 직접 그렸으므로 «그 자리에 실제 열 경계가 있는가» 를
잴 수 있습니다.

| 등급 | 기준 | 개수 |
|---|---|---|
| 확인 | 적합도 ≥ 1.15 | **23** |
| 보류 | 0.85 ~ 1.15 | 8 |
| 미확인 | < 0.85 | **1** |

보류·미확인은 **틀렸다는 뜻이 아닙니다.** 그 구역의 대비가 약해 확인도
반증도 안 된다는 뜻이고, 지우지 않고 수치로 남겨 쓰는 쪽이 판단하게 했습니다.
→ [`figures/검수/`](figures/검수)

| | 상태 |

| `.152` 의 꽃·딸기 | **불가** — 열화상으로 안 갈립니다 |
| 절대 엽온 정확도 | 오차 예산 0.56 ℃ 와 신호(0.4~0.65 ℃)가 같은 크기입니다. 개체 **간** 비교는 유효하고, 절대값은 아직입니다 |
| 잎−기온 VPD | 이 보고서 범위 밖 — 환경센서 결합은 [중간보고 §4](../mid-term/README.md) |

**절대 보정의 실마리가 생겼습니다.** `.152` 어노테이션에 **엽온센서 2개**가
잡혔습니다(적합도 2.86 / 1.32, 배경보다 +0.78 / +0.48 ℃). 접촉식 기준면이
화면 안에 있다는 뜻이라, 그 값을 읽어 오면 절대 오프셋을 물을 수 있습니다.

└── figures/
    ├── 일자별/        11장  카메라·날짜별 4패널 그래프
    ├── 마스크_151/    62장  RGB 낱장 · 열화상 · 나란히 대조 (층·분류별)
    ├── 마스크_152/    48장  열화상 (층·분류별)

### `leaf_temp_all.csv` 주요 열

| 열 | 뜻 |
|---|---|
| `카메라` `날짜` `시각` `시` | 언제, 어느 구역 |
| `개체` `분류` `층_mm` `면적_px` | 무엇을 |
| **`엽온_C`** | 그 슬롯 평균 온도 (FFC 상쇄 위해 슬롯 전체 프레임 평균) |
| `화면평균_C` | 같은 슬롯의 화면 전체 평균 — 편차를 볼 때 기준 |
| `점등` | 1 = 08:01~18:01 |
| `마스크판정` `보정dx` `보정dy` | 그 날을 어떤 근거로 채택했나 |
| `유효프레임` `전체프레임` `슬롯온전` | 0 이면 녹화가 잘린 슬롯 — 절대값보다 편차를 쓰십시오 |
| `마스크적합` `열구조세기` | 그 슬롯에서 마스크가 경계에 얼마나 얹혔나 |
