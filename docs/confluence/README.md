# Confluence 게시 방법

이 폴더는 **Confluence 붙여넣기 전용** 사본입니다. 원본·근거는
`docs/thermal_rgb_calibration.md` §5-5 에 있습니다. 내용을 고칠 때는 원본을
먼저 고치고 여기로 반영하십시오.

| 파일 | 용도 |
|---|---|
| `열화상_캘리브레이션_2차_촬영표.md` | 본문 |
| `fig1_board_layout.png` | 보드 배치 (중앙 / 좌 / 우하) |
| `fig2_tilt.png` | 기울임 비교 (8° vs 30°) |
| `fig3_caliper.png` | 캘리퍼스 베이스라인 측정법 |
| `fig4_orientation.png` | 판을 드는 방향별 최대 크기 (눕혀서 / 45° / 세워서) |
| `*.svg` | 위 그림들의 원본. 수정이 필요할 때만 사용 |

그림은 `scripts/mkfigs.py` 로 생성했습니다. 배치·기울임 그림은 **실제 투영
계산**(f 208.4, 칸 17 px)으로 그려서 현장 미리보기와 같은 모양입니다.

## 순서

1. Confluence 새 페이지 → 제목 `열화상 캘리브레이션 2차 촬영표`
2. **그림 4개를 먼저 첨부합니다.** 본문에 드래그해 넣거나, 페이지 하단
   *Attachments* 에 업로드
3. `열화상_캘리브레이션_2차_촬영표.md` 전체를 복사
4. 편집기에서 **`/markdown`** 입력 → **Markdown** 매크로 선택 → 붙여넣기
   (또는 상단 **+ → Markup → Markdown**)
5. 변환된 뒤 이미지 자리를 확인 — `![...](fig1_board_layout.png)` 는 그대로
   렌더되지 않으므로, 그 줄을 지우고 **첨부한 이미지를 직접 삽입**하십시오
   (`/image` → Attachments 에서 선택)

## 다듬으면 좋은 것

| 항목 | 방법 |
|---|---|
| 인용문(`>`)을 패널로 | 해당 블록 선택 → `/info` 또는 `/warning` 매크로 |
| 체크박스 | `- [ ]` 는 대개 Action item 으로 변환됩니다. 안 되면 `/task` |
| 표 강조 | 판정 표의 «실패» 행에 셀 배경색(빨강 계열) |
| 목차 | 맨 위에 `/toc` |

## 그림을 고쳐야 할 때

```bash
python3 scripts/mkfigs.py       # fig1~3 재생성
python3 scripts/fig_orient.py   # fig4 재생성
```

색상·크기 상수는 스크립트 상단에 모여 있습니다. 흰 배경 고정이라 Confluence
다크 모드에서도 그대로 보입니다.
