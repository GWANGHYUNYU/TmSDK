## 3. 현재 숫자와 적용 범위

`output/leaftemp/`와 최신 보고 `data/` CSV를 직접 재집계했다.

| 항목 | 확인 값 |
|---|---|
| 측정 날짜 | 2026-09-17~23, 달력 날짜 7개 |
| 채택 카메라-일 | `.151` 5 + `.152` 6 = 11 |
| 고유 슬롯 | 447, 키는 카메라·날짜·시각 |
| 상세/일별 영역 요약 | 23,119행 / 567행 |
| 영역 | `.151` 75(잎60·꽃12·딸기3), `.152` 32(잎29·딸기1·센서2) |
| 날짜별 심사 19건 | 확인5·주의3·보정3·불가6·판정불가2 |
| 불완전 슬롯 | 4건, 상세 CSV에 품질 표지와 함께 포함 |

현재 `프레임/ROI` 키는 실제 작물 ID가 아니다. 같은 잎의 프레임 간 중복과
여러 잎의 화분 대응은 등록이 필요하다. 정합 성적은 절대온도 성적과 다르며,
1000mm 층의 H와 GSD는 모델 외삽이다. `.152` 깊이·층은 별도 검증이 필요하다.

8월 마커 분석의 1.74℃와 9월 잎 평균 구역 차이 0.45~0.55℃는 시기·ROI·
평균 방법이 달라 전후 성능으로 직접 비교하지 않는다. 야간 구역 차이가 작다는
관측은 송풍 가설을 뒷받침하지만 구역 교란·온도 의존 보정 오차를 모두 배제한
인과 증명은 아니다. 자세한 한계는 [검토 §5](project_review.md#5-확인된-연구-결과와-해석-한계).

## 5. 구현 전에 점검할 코드 경계

- `leaf_temp_export.py`의 `점등`은 08:00~18:00이고 보고 그림은 08:01~18:01이다.
- 엽온 출력은 HH:MM 시작시각만 남긴다. 센서 결합에는 메타 timestamps와 실제 슬롯 구간이 필요하다.
- 마지막 영역별 편차 요약은 날짜·시각으로 두 카메라를 혼합 평균한다. 구역별 기준으로 분리할 작업이다.
- `slot_mean()`은 0으로 채워진 비정상 프레임을 제외하지만 FFC 직후 제외 함수를 사용하지 않는다.
- 파일 읽기 실패가 건너뛰어지고 불완전 슬롯도 품질 표지와 함께 포함된다. VPD·제어용 채택 규칙이 필요하다.

이번에는 코드와 결과 CSV를 변경하지 않았다. 항목별 근거와 영향은
[검토 §6](project_review.md#6-문서와-코드의-불일치다음-구현-점검)에 기록했다.

확정 파라미터는 [`params/`](../params/README.md), 데이터/도구 규약은
[data_and_tools.md](data_and_tools.md), 방향/정합 절차는
[calibration_final.md](calibration_final.md)를 따른다.
Y16+메타/LUT, 환경 CSV, 수동 어노테이션은 보존한다.
분석 전처리의 프레임 평균 차감·배경 제거는 구조 분석용이며 절대 엽온에 사용하지 않는다.

기존 인수인계에 공개 저장소의 과거 보고서 blob 삭제 미처리 기록이 있다.
이번 검토에서 원격 상태는 확인하지 않았고 외부 게시·푸시도 하지 않았다.
원문·현장 데이터 보존과 공유 범위는 기존 과업 및 운영 정책으로 관리한다.
