## ★ RGB 를 뒤집어 보여 줍니다

**RGB 영상은 180° 뒤집혀 녹화됩니다.** 도구는 이것을 바로 세워서 보여 주고,
**좌표는 원본 파일 좌표로 저장**합니다. 그래서 내보낸 JSON 을 그대로 투영에
쓸 수 있습니다 — 따로 뒤집지 마십시오.

자료로 확인한 근거입니다. 같은 순간의 두 영상에서 세로 방향 추세를 보면:

| 구간 (위→아래) | RGB 원본 | **RGB 뒤집음** | 열화상 원본 |
|---|---|---|---|
| 맨 위 | 199.7 | **86.1** | 19.44 ℃ |
| 맨 아래 | 86.1 | **199.7** | 20.92 ℃ |

**뒤집은 RGB 가 열화상(원본)과 같은 방향**입니다. 원본 RGB 는 정반대입니다.

> 캘리브레이션 자체는 영향받지 않습니다. `H` 는 **원본 RGB → 180° 돌린
> 열화상** 을 잇는데, 이것은 「뒤집은 RGB → 원본 열화상」과 같은 대응입니다.
> **한쪽만 돌리면 됩니다. 양쪽 다 돌리면 틀립니다.**

## ★ 층 — 화면 어디가 몇 mm 인가

캐노피 세 층이 **한 화면 안에** 들어옵니다. 개체마다 층을 골라 주십시오.

| 층 | 원본 RGB 의 y | **뒤집은 화면(도구에서 보이는 것)** |
|---|---|---|
| **420 mm** (가장 가까움) | y ≈ 1000 (아래) | **위쪽** |
| **700 mm** | y ≈ 600~800 | 가운데 |
| **1000 mm** (가장 멂) | y ≈ 400~600 | 그 아래 |

**층을 잘못 고르면 투영이 7~11 화소 어긋납니다** — 정합 오차(0.93 px)의
8~12 배입니다. 개체 크기를 생각하면 다른 그루를 짚게 됩니다.

도구 화면의 테두리 세 개가 층별 열화상 화각입니다 (파랑 420 · 초록 700 ·
주황 1000). **테두리 밖은 열화상 데이터가 없어 칠해도 쓸 수 없습니다.**

## 무엇을 개체로 볼 것인가

**한 화분에서 자란 것 전체** — 잎·줄기·화방 포함. 화분(검은 용기)은 빼고.

| 상황 | 어떻게 |
|---|---|
| 앞줄이 뒷줄을 가림 | **보이는 부분만.** 상상해서 채우지 말 것 |
| 뒷줄이 흐림 | **흐린 대로.** 열화상은 160×120 이라 훨씬 거칩니다 |
| 판단이 안 서는 것 | **넘어가십시오.** 애매한 것을 억지로 칠하면 모델이 그 애매함을 배웁니다 |

## 내보내기

| 버튼 | 내는 것 |
|---|---|
| **JSON 저장** | 모든 장의 개체. 좌표·층·이름표. 투영 스크립트가 읽습니다 |
| **마스크 PNG** | 지금 장의 면(폴리곤·사각형)을 개체별 색으로 칠한 1920×1080 |
| JSON 불러오기 | 저장했던 작업을 이어서 |

JSON 모양:

```json
{
 "coordinate_note": "원본 RGB 파일 좌표(1920×1080, 뒤집지 않은 상태)",
 "images": [{ "image": "08-00-15_f01527.png",
   "objects": [
     {"id":"obj1","type":"poly","layer_mm":420,"label":"6-4",
      "points":[[812.0,430.5], ...]}
   ]}]
}
```

투영은 이렇게 합니다.

```python
und = cv2.undistortPoints(pts, K_rgb, dist_rgb, P=K_rgb)   # 왜곡 풀기
th  = cv2.perspectiveTransform(und, H[layer_mm])            # 그 층의 H
# 결과는 «180° 돌린» 열화상 좌표계
```

## 먼저 1~2장만

투영이 제대로 되는지 확인한 뒤에 나머지를 하시는 게 안전합니다.
칠한 것을 열화상에 얹어 **잎이 있는 자리에 마스크가 오는지** 봅니다.

마스크가 **한쪽으로 일정하게 밀리면** 정합이 아니라 「층을 정면 평면으로
본다」는 가정을 먼저 의심하십시오
([최종 보고 4장](../docs/calibration_final.md)).

## 화각 경계를 다시 계산하려면

`fov.json` 과 `annotator.html` 안의 `FOV` 상수는
`params/thermal_rgb_stereo.npz` 로 계산한 값입니다. 파라미터가 바뀌면:

```bash
python3 scripts/make_annotate.py <rgb.mp4> <thermal.y16raw> --out output/annotate_v3
```

가 새 다각형을 `index.json` 에 냅니다. 도구의 **JSON 불러오기**로 그 파일을
넣으면 테두리가 갱신됩니다.
